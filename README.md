# Shelfwise

The web shop of a small independent bookshop: browse the catalogue, add books
to a cart, check out with a name and shipping address, and see the order. The
shop owner sees every order and marks them shipped. There is no sign-in and no
payment step: placing an order records it.

Built with Next.js (App Router), Drizzle ORM on SQLite, and Tailwind CSS.

## Getting started

```bash
npm ci
npm run db:setup   # creates shelfwise.db, applies migrations, loads sample data
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

`npm run db:setup` can be run again at any time: it replaces everything in the
database with the sample shop.

## How it works

- **Books** have a title, author, ISBN, genre (Fiction, Mystery, Science or
  History), year, description, price and the number in stock. Money is stored
  as whole cents.
- A **cart** belongs to one browser, which keeps the cart's token in the
  `cart_token` cookie. The cart is created on the first add to cart. Adding a
  book that is already in the cart raises its quantity; a quantity of 0 removes
  the line. A cart line can never ask for more than the book's stock.
- **Checkout** turns the cart into an **order** (`ORD-0001`, ...) in one step:
  each book's title and current price are copied onto the order, the quantities
  come out of stock, and the cart is emptied. If any book no longer has enough
  stock, nothing changes and the checkout page says so.
- An order is `placed` until the shop marks it `shipped`.
- Cart and order totals are worked out when they are shown, never stored: the
  cart at today's prices, an order at the prices it was placed at.

| Path                    | What it is                                     |
| ----------------------- | ---------------------------------------------- |
| `db/schema.ts`          | the tables                                     |
| `drizzle/`              | migrations, generated by `npm run db:generate` |
| `db/seed.ts`            | the sample shop                                |
| `lib/`                  | catalogue, cart and order logic, and its tests |
| `app/`                  | pages and form actions                         |

## Changing the database

Edit `db/schema.ts`, then:

```bash
npm run db:generate   # writes a new migration into drizzle/
npm run db:migrate
```
